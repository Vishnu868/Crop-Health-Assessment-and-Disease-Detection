# Results

Everything here was produced by the scripts in this repository on **real PlantVillage data**
(8,000 images, 5 classes; test split = 1,200 images, 240 per class). `summary.md` has all the tables.

| Path | Contents |
|---|---|
| `summary.md` | All result tables (auto-generated by `scripts/make_figures.py`) |
| `classification/<model>/metrics.json` | test accuracy, macro-F1, macro AUC, per-class report, confusion matrix, background-removed test, training history |
| `classification/<model>/classification_report.txt` | sklearn per-class precision / recall / F1 |
| `classification/<model>/test_predictions.npz` | test-set softmax probabilities, labels and dataset indices |
| `classification/baselines_handcrafted/metrics.json` | majority class, colour+texture features + logistic regression / random forest |
| `classification/synthetic_*` | **synthetic sanity check only** (generated images, not real data) |
| `detection/<model>/metrics.json` | test P, R, mAP@0.5, mAP@0.5:0.95 (overall + per class) and image-level accuracy / confusion matrix |
| `detection/<model>/*.png, results.csv` | Ultralytics training curves, PR curve, normalised confusion matrix |
| `models/*.pt` | trained checkpoints: classifiers (`state_dict` + model name) and detectors (Ultralytics format, `det_*.pt`) |

Model names: `yolo26_cls_sfr` = proposed (YOLO26n-cls + SFR); `yolo26_cls` = without SFR; `yolo11_cls(_sfr)` =
YOLO11n-cls backbone; `*_scratch` = no ImageNet pretraining; `*_bgaug` = trained with 50% background-removed images;
`small_cnn` = 4-block CNN from scratch. Detectors: `yolo26n_sfr` (proposed), `yolo26n`, `yolo11n`, `yolov5nu`.

Run a trained model:

```bash
python -m src.predict leaf.jpg                                   # classifier + advisory + health score
python -m src.predict leaf.jpg --detector results/models/det_yolo26n_sfr.pt --gradcam cam.png
```
